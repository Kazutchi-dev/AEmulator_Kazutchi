# AEmulator Kazutchi 0.0.0.11

## Update discovery fix
- Select the highest stable semantic version among published APK releases instead of trusting GitHub API ordering.
- Ignore draft and prerelease releases when selecting the update target.
- Continue to skip releases without a valid APK download URL.

## Included changes
- Fixes the update checker selecting v0.0.0.9 ahead of v0.0.0.10 when the GitHub Releases API returns them in a non-version order.
- Includes the GPU settings persistence and boot diagnostics fixes from v0.0.0.10.

## Validation
- Debug and signed release CI builds are run for this version.
- Device-side update discovery, download, signature compatibility, and HTC guest boot still require confirmation.
