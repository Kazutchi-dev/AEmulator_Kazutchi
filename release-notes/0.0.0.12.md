# AEmulator Kazutchi 0.0.0.12

## Runtime diagnostics and Binder isolation

- Record host PID, parent PID, process group, session, cgroup membership, and OOM score for each guest service at launch.
- Capture host memory availability, swap, memory pressure, OOM-kill counters, and cgroup memory events after the first unexpected guest SIGKILL (exit code 137).
- Clarify that preserving guest processes disables only AEmulator's internal GuestLmk policy; it cannot prevent the Android host kernel from killing processes under OOM pressure.
- Launch the Android 4.x Binder daemon through the existing dhdrun wrapper so it receives its own process group, matching the other guest services.

This is a diagnostic build. It does not claim to resolve the underlying cause of the previous simultaneous guest-process exits.
