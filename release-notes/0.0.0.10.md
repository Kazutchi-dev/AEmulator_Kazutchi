# AEmulator Kazutchi 0.0.0.10

## GPU settings reliability
- Wait for per-image settings to be written and read back successfully before closing the settings sheet.
- Prevent dismissing the settings sheet while the save is in progress, avoiding a stale-settings boot race.
- Record the exact GPU and HWUI settings snapshot used by each boot.
- Remove the app-managed automatic ANGLE route when GPU acceleration is switched off.

## Compatibility and diagnostics
- GPU-disabled boots now explicitly report the software-rendering path.
- Existing user-managed graphics flags are preserved; only AEmulator-managed ANGLE flags are cleared automatically.

## Validation
- Debug and signed release builds are run by GitHub Actions for this commit.
- Physical-device HTC One guest boot and SurfaceFlinger stability still require confirmation on the user's device.
