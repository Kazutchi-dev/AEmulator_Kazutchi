# AEmulator Kazutchi 0.0.0.9

## ANGLE graphics integration
- Added a system ANGLE preference on Android 17+ for supported GLES rendering paths.
- Enabled the in-process GLES host route for modern KK guests (API 19+) on supported hosts.
- Added renderer diagnostics and a fallback to the isolated renderer if direct rendering cannot start.
- Built and packaged the KK 32-bit guest GLES bridge.

## Compatibility
- Legacy GB and KK guests below API 19 retain the isolated renderer.
- Existing app identity and persistent signing identity are preserved.

## Validation
- Android NDK guest bridge build: passed.
- Standard debug build and engine asset packaging: passed in CI.
- This release pipeline verifies the signed APK and package/version metadata before publishing.

## Known limitations
- ANGLE selection depends on Android's system graphics driver implementation; the preference is not a guarantee.
- Vulkan backend selection, real-device stability, and performance gains are not yet verified on physical hardware.
- Legacy graphics paths are intentionally not migrated in this release.
